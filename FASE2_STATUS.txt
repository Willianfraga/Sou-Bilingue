🔄 FLUXO DE UMA SESSÃO

  1. Aluno acessa /aluno/aula
  2. AulaChatComHoras monta
     └─ useUsageSession({ autoStart: true })
  3. Hook busca sessão ativa no servidor
     └─ Se existe: carrega; se não: aguarda clique
  4. Aluno clica "Começar Conversação"
     └─ startSessionAction()
        ├─ Valida autenticação
        ├─ Busca subscription ativa
        ├─ Verifica horas_restantes > 0
        └─ Cria entry em usage_sessions
  5. Hook recebe sessionId
     └─ Inicia timer (1s local, 10s sync)
  6. [Aluno conversa por 45 minutos]
  7. Timer monitora:
     ├─ A cada 1s: incrementa elapsedTime
     ├─ A cada 10s: sync com servidor
     ├─ Ao atingir 15 min: onTimeWarning()
     └─ Ao atingir 1h: forceEndSessionByTimeout()
  8. Aluno clica "Encerrar"
     └─ endSessionAction(sessionId)
        ├─ Calcula duração total (45 min)
        ├─ UPDATE usage_sessions (ativo=false)
        ├─ INSERT em usage_ledger (tipo='uso')
        ├─ UPDATE subscriptions (horas_utilizadas++)
        └─ Retorna horasConsumidas
  9. UI atualiza
     └─ HourUsageTracker busca nova subscription
        ├─ Mostra horas_restantes reduzidas
        └─ Oferece novo "Começar"
