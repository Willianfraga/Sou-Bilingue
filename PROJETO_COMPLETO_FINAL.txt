🚀 FLUXOS PRINCIPAIS
═══════════════════════════════════════════════════════════════════════════════

1️⃣  CHECKOUT ASSINATURA
    Aluno → /checkout → seleciona plano → Asaas → paga → webhook → ativa

2️⃣  SESSÃO COM RASTREAMENTO
    "Começar" → timer local → sync 10s → alertas → encerra → calcula horas

3️⃣  RECARREGAR HORAS
    "Recarregar" → seleciona pacote → Asaas → paga → credita horas → expira em 1 ano

4️⃣  VER DASHBOARD
    Acessa /aluno/dashboard → carrega 5 dados paralelos → exibe resumo + gráficos

5️⃣  EXPORTAR DADOS
    Clica botão → gera CSV/PDF → download automático no browser

6️⃣  ADMIN VISUALIZA PLATAFORMA
    Acessa /admin/dashboard → requireAdmin() → carrega stats → exibe metrics
